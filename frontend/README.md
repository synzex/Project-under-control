# FlowGantt — MVP (React + TypeScript)

MVP планировщика проектов с диаграммой Ганта. Сделано под хакатон-кейс
«Проект под контролем».

## Стек

- React 19 + TypeScript
- Vite 8 (dev-сервер и сборка)
- Tailwind CSS v4 (через `@tailwindcss/vite`, токены — в `src/index.css`)

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build       # прод-сборка в dist/
npm run typecheck   # только проверка типов, без сборки
```

## Структура

```
src/
  types.ts               — доменные типы (Project, Task, статусы, формы)
  data/seed.ts            — демо-данные (project + tasks), даты считаются от реального "сегодня"
  state/useAppState.ts     — стейт приложения и CRUD-операции (create/update/delete)
  utils/date.ts            — работа с датами
  utils/domain.ts          — статус задачи, цвета, обход графа зависимостей (BFS)
  components/
    Header.tsx
    ProjectList.tsx        — список проектов
    ProjectModal.tsx       — создание проекта
    ProjectDetail.tsx      — экран проекта: фильтры + список задач + Гант
    TaskSideList.tsx        — левая колонка со списком задач
    GanttChart.tsx           — диаграмма Ганта: бары, зависимости, "сегодня"
    TaskDrawer.tsx            — создание/редактирование задачи
    StatusFilters.tsx          — фильтр по статусу
  App.tsx                      — маршрутизация между list/detail, модалки, стейт подсветки
```

## Что реализовано (по чек-листу кейса)

- Создание проекта (название, сроки)
- CRUD задач: создание / редактирование / удаление
- Диаграмма Ганта: даты начала/конца, длительность, статус, зависимости
- Зависимости между задачами (visual: стрелки), защита от циклических зависимостей
  при выборе предшественника
- Изменение сроков/статуса/ответственного у существующей задачи
- Автоматический расчёт "Просрочено" (дедлайн прошёл, статус ≠ "Готово")
- При сдвиге сроков — подсветка потенциально затронутых (downstream) задач
  и баннер с их названиями
- Поиск и фильтрация задач по статусу
